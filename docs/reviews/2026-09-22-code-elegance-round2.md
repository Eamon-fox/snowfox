## R6. 表格查询与 Qt 渲染分离

- 回归：当前/历史视图、草稿搜索、排序、分页及查询纯函数测试。
- 状态：已完成。
- 结果：核心 query_table_projection 提供唯一筛选/排序/分页管线；GUI query_current_rows 使用显式参数，历史查询由筛选控制器编排；删除 5 个表格查询 helper、3 个主面板绑定及仅有测试调用的旧筛选函数。
- 统计：生产代码净减少 105 行（阶段汇报为 104 行，最终清理文件末尾空行再减少 1 行）。
- 回归：GUI/库存查询/bridge 110 passed + 56 subtests；新增无窗口投影测试 3 passed。工具行字段继续裁剪，不泄漏记录或搜索元数据。
