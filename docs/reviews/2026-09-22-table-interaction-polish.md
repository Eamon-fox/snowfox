# 2026-09-22 表格视觉与 Pending 阅读体验

## 范围

- 模块：gui_presentation；不修改共享瓶颈点、库存规则或执行流程。
- 用户确认双层框问题发生在库存概览表格；Pending 问题是内容撑宽和滚动条难拖。

## 实施

- 库存选中态不再切换到另一套文字绘制方式；统一文字内边距，移除叠加的原生单元格焦点框，保留行高亮、键盘选择和双击/F2 编辑。
- 两个表格使用同一个带色彩背景的 delegate；文字/日期/选项编辑器限定为固定的一像素边框，不继承普通表单焦点时加粗边框的几何变化。
- Pending 列宽随 viewport 适配，刷新内容不再按最长字段撑宽所有列；日期保留可读宽度，长文本按可见行数换行和省略。
- 选中任务显示可复制的完整详情，包含批量位置、变更和状态；内容纵向滚动。支持多行选择、移除后清理详情，执行入口不变。
- Pending 表与详情滚动条拖动区域加宽至 10px，仍用像素滚动；用户仍能手动调整列宽。

## 验证

- 实际 Qt 离屏渲染检查浅色/深色主题、420px/560px 宽度，以及库存选择前后效果；两个宽度下默认横向滚动范围均为 0。
- 焦点前后像素一致性、窄面板适配、完整详情与清空行为及浅/深色滚动条回归：20 passed。
- 整体 GUI 测试：605 passed、63 subtests passed（54.66 秒）；Ruff 与 diff 检查通过。
- 40 行、420px 窄表检查：垂直滚动条宽度 10px，无默认横向溢出。
- 修正 Qt 在表格命名之前缓存滚动条样式的问题；表格初始化时重新应用滚动条样式，验证首次打开时也生效。
- 回归期间发现已运行桌面进程占用 37666，原 token 测试可能命中已有服务；测试内部将默认端口设为随机空闲端口并检查启动成功，未修改运行服务或 API 生产实现。
