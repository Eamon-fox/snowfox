- AI 模型更新：DeepSeek 默认使用官方 `deepseek-flash` 别名；智谱默认升级至 GLM-5.3，并可选择 GLM-5.3-Flash / FlashX。旧模型配置自动迁移，GLM-5.3 系列按官方要求使用推理强度开关。

### 修复

- 修复库存概览表格选中时出现双层焦点框、文字位移的问题。
